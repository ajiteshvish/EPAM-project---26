## 🚀 Key Features & Capabilities

- 💰 **Account Balance & Cash Engine**: Instant deposit and cash withdrawal actions with real-time balance calculations.
- ⚡ **UK Faster Payments (`/transfers`)**: Peer-to-peer transfers featuring beneficiary quick-select pills, account validation, and confirmation modals.
- 🧾 **Audit Transaction Ledger (`/transactions`)**: Search, filtering, sorting, and CSV export.
- 💳 **Card Security Rules (`/cards`)**: Card preview, freeze/unfreeze, online, international, and contactless controls.
- 💾 **SSR-Safe LocalStorage**: Persists demo banking state across browser refreshes.
